# GIS Automation Toolbox (ArcGIS Pro)

Python toolbox (`GISAutomation.pyt`) for ArcGIS Pro 3.x.

| Tool | What it does |
|---|---|
| Batch Project | Reprojects every feature class of a workspace (incl. feature datasets), optional datum transformation |
| Batch Clip & Export | Clips several layers to one area of interest |
| QC Checks | CSV report: Check Geometry problems, duplicate geometries, empty required fields, undefined CRS |
| GIS to CAD | Exports layers to DWG / DXF |
| Package Deliverables | Copies maps / reports / CAD files into a dated folder and zips it |

**Install:** ArcGIS Pro → Catalog pane → Toolboxes → *Add Toolbox* → select `GISAutomation.pyt`.
